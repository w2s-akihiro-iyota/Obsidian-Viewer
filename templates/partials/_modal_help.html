基本操作

ファイルツリー

サイドバーのファイルタブに、Vault のフォルダ構成がそのまま表示されます。
開いているノートまで自動で展開し、閉じたフォルダには中のノート数が出ます。上の入力欄でファイル名を絞り込めます。 {% if viewer_is_admin %}
非公開ノートには、ツリーにも一覧にも錠前の印（非公開）が付きます。{% endif %}

クイックスイッチャー

Ctrl+K（Mac は ⌘+K）か上部の検索バーで開きます。
何も入力しないと、最近見たノートが並びます。tag:会議・path:フォルダ名 で絞り込めます。
開いたノートでは、検索した言葉に色が付き、最初の一致まで移動します。

記事のヘッダー

タイトルの上のパンくずでフォルダ名を押すと、そのフォルダのノート一覧に移ります。
タイトルの下に、公開状態・更新日・読了時間・リンク元の数が並びます。リンク元を押すとページ下部へ移ります。

リンク元と関連記事

記事の下に、このノートへリンクしているノート（リンク元）と、タグが共通する関連記事が表示されます。

ノート一覧

トップページの一覧は、右上のアイコンでリスト表示とグリッド表示を切り替えられます。
一覧の上で並び順（更新日・タイトル・文字数）とタグを選べます。タグは件数の多い順に並び、「＋ほか」で全部のタグを開けます。
{% if viewer_is_admin %}公開・非公開でも絞り込めます。
{% endif %} 絞り込み中は件数の横に条件が出て、× で 1 つずつ外せます。

目次と閲覧履歴

サイドバーの目次タブに見出しの一覧が出ます。押すとその場所へ移ります。
閲覧履歴タブには、最近開いたノートが30件まで残ります。

スマホでの画面の移り方

スマホでは左端のアイコンの列が隠れます。左上のボタンでサイドバーを開くと、一番上にノート・グラフの切り替えがあります。 {% if viewer_is_admin %}
管理者にはダッシュボード・エディタも並びます。{% endif %}

グラフビュー

左端のアイコンからグラフを開くと、ノートとリンクのつながりを図で見られます。開いたときは全部の点が収まる大きさで表示します。
記事ページの右上のボタン（G）で、いま読んでいるノートの周りだけの小さなグラフを開けます。ボタンの数字は 1 歩でつながっているノートの数です。「1 歩」「2 歩」でつながりの深さを切り替え、点を押すとそのノートへ移ります。

記事のメニュー

記事右上の「⋮」から、URLのコピーとPDF出力・印刷ができます。
画像は押すと拡大します。コードブロックは右上のボタンでコピーできます。

ファイル同期の設定手順

ローカルの Obsidian フォルダを本システムと同期させるには、以下の手順を行ってください。

1

画面左端のアイコン列の下にある 歯車マーク をクリックして設定画面を開きます。

2

「システム＞ファイル同期」セクションで、「ファイル同期を有効にする」のトグルボタンを有効します。

3

同期したいローカルパスを入力します。

・コンテンツの元フォルダ： Markdownファイルが格納されているフォルダ
・画像の元フォルダ： 画像ファイルが格納されているフォルダ（任意）
・公開URL：他の人にページのURLを公開する際に、アクセス可能なドメイン名を含めたベースURLを設定してください（任意）

ヒント：
パスは、インストール時に編集した docker-compose.yml の ObsidianVault フォルダからの相対パスで指定してください。
例：/0_host_pc/003_Notes

4

「設定を保存」ボタンをクリックして設定を保存する。

ヒント：
設定を保存するだけで、同期は即時に行われません。
各パスの入力チェックが行われ、問題が無ければ保存に成功します。

5

「今すぐ同期」ボタンをクリックして、設定したパスからファイルの同期を開始する。

ヒント：
同期は即時に行われますが、ファイルの変更を検知するには、数秒程度の待ち時間がかかることがあります。

同期で起きること

  • Vault で消したノートは、ビューアからも消えます。
  • 一度にたくさん消えるときは、削除を止めて確認を待ちます。
    • ビューアのノートの半分以上が消える場合や、同期元のフォルダが空の場合です（フォルダの指定ミスやドライブ未接続で全部消えるのを防ぐため）
    • 設定画面に出る「確認して削除する」を押すと、削除を実行します
  • 同期中にもう一度同期しようとしても、二重には動きません。「同期を実行中です」と表示されます。
  • 自動同期の間隔は、設定画面で「自動同期を有効にする」をオンにすると選べます。
  • 再インデックスは、検索やリンクの結果が古いと感じたときに使います。設定画面の「コンテンツの再インデックス」の「再構築」を押すと、同期せずに、いまのファイルから索引だけを作り直します。

記事の公開設定

公開用ポート（8000）からアクセスされた場合、Frontmatter に publish: true が設定されたファイルのみが表示されます。
管理用URL（http://localhost:8002）からのアクセスでは、すべてのファイルが閲覧可能です。

公開用ポートでは、タグ一覧・検索・Dataview・グラフ・リンク元も、公開ノートだけを対象にします。

方法1: Obsidian Linter プラグインで自動付与する（推奨）

Obsidian のコミュニティプラグイン「Linter」を使うと、保存時に Frontmatter を自動挿入できます。

1

Obsidian の 設定 > コミュニティプラグイン から「Linter」をインストールして有効化する

2

Linter の設定画面を開き、YAML > Insert YAML Attributes > トグル を ON にして Text to insert のテキストボックス に以下を設定する

publish: true

3

ファイル保存時に publish: true が Frontmatter に自動追加される

ヒント：
特定のファイルを非公開にしたい場合は、手動で publish: false に変更するか、Obsidianから変更してください。

方法2: 手動で Frontmatter に記述する

Markdownファイルの先頭に、以下のように記述します。

---
publish: true
---

publish: true のないファイルは、外部からのアクセス時に非公開（403エラー）となります。

共有URLの設定

記事ページの「URLをコピー」機能では、デフォルトで今開いているURL（localhost:8002 など）が生成されます。
外部の人にURLを共有する場合は、公開URL (Base URL) を設定することでドメイン部分を置換できます。

1

画面左端のアイコン列の下にある 歯車アイコン から設定画面を開く

2

システム > ファイル同期 タブを選択する

3

「公開URL (Base URL)」欄に、外部からアクセス可能なURLを入力する

例: http://{PC名}:8000

4

「設定を保存」をクリックする

設定後の動作：
URLコピー時に http://localhost:8002/view/記事名.md が https://{PC名}:8000/view/記事名.md に自動置換されます。

注意：
公開URLは、ポートフォワーディングやリバースプロキシなどで外部からアクセスできる状態になっている必要があります。 本設定はURLコピー時の置換のみを行い、ネットワーク設定自体は変更しません。

公開チェック（外部の人の表示）

公開する前に、外部の人にどう見えるかを記事ページで確かめられます。

1

確かめたい記事を開きます。問題があると、ヘッダーの「外部の人の表示」ボタンに「要確認 N」の件数が出ます。

2

ボタンを押すと、外部の人と同じ表示に切り替わり、本文の上にチェック結果が出ます。

・非公開ノートへのリンク：外部ではリンク切れに見えます
・非公開ノートの埋め込み：外部では中身が出ません
・存在しないノートへのリンク
・見つからない画像
・Dataview で外部に出ない結果：非公開ノートは一覧から外れます
・ノート自身が非公開なら、外部からは 403 になると表示します

3

「通常の表示に戻る」を押すと、管理者の表示に戻ります。

ノートの編集

既存のノートを直す

記事右上の「⋮」→「編集」で開きます。Ctrl+S で保存します。
保存先は Vault の元ファイルです。

ほかで更新されていたとき

開いたあとに Obsidian 側でファイルが変わっていたら、上書きせずに知らせます。 「最新を読み込み直す」（入力中の内容はクリップボードへコピー）か、「それでも上書きする」を選んでください。

新しいノートを作る

左端のエディタのアイコンから、新しいノートを作れます。
同期元フォルダの直下に保存されます。同じ名前のノートがあると保存できません。

Docker で動かしている場合、Vault を読み取り専用（:ro）でマウントしていると保存できません。書き込みを許すマウントに変えてください。

ダッシュボード

左端のアイコンから開きます。ノートの件数（公開・非公開の内訳）と総文字数、最終更新日の分布（ヒートマップ）、最近更新したノート、タグの集計を確認できます。
手入れが必要なノートとして、リンク切れ・どこからもリンクされていない孤立ノート・タグのないノートの件数が出ます。カードを押すと、該当するノートの一覧が開きます。

{% endif %}

表示機能とカスタマイズ

設定画面では、閲覧体験を向上させるための様々なカスタマイズが可能です。

  • 基本設定:
    • フォントサイズ: 本文の文字サイズを「小・中・大」から選択できます。
    • 読みやすい行幅: 本文の最大幅を制限し、長文でも読みやすくします（トグルで切り替え）。
    • 行番号を表示: コードブロック内だけでなく、本文全体に行番号を表示します。
  • 外観テーマ:
    • アプリのテーマ: ダーク、ライト、レター、ミッドナイトから選択できます。
    • コードブロックのテーマ: プログラミング言語などのコード表示の色合いを変更できます。
    • Mermaid図のテーマ: フローチャートや図表の配色を、テーマに合わせて最適化できます。
